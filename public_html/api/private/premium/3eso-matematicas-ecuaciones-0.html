1. Ecuaciones bicuadradas

Son de la forma \(ax^4 + bx^2 + c = 0\). Se resuelven con el cambio de variable \(z = x^2\), que las convierte en una ecuación de segundo grado.

Ejemplo: \(x^4 - 13x^2 + 36 = 0\)
  1. Cambio \(z = x^2\) → \(z^2 - 13z + 36 = 0\).
  2. \(\Delta = 169 - 144 = 25\) → \(z = \frac{13 \pm 5}{2}\) → \(z = 9\) o \(z = 4\).
  3. Deshacemos el cambio: \(x^2 = 9 \Rightarrow x = \pm\sqrt{9} = \pm 3\); \(x^2 = 4 \Rightarrow x = \pm\sqrt{4} = \pm 2\).
  4. Soluciones: \(x = -3,\ -2,\ 2,\ 3\).
CuidadoSi al deshacer el cambio sale \(x^2\) igual a un número negativo, ese valor no da soluciones reales.

2. Ecuaciones con la x en el denominador

Se multiplica todo por el m.c.m. de los denominadores y, al final, se descartan las soluciones que anulen algún denominador.

Ejemplo: \(\frac{1}{x} + \frac{1}{x + 2} = \frac{4}{3}\)
  1. m.c.m. = \(3x(x + 2)\). Multiplicamos: \(3(x + 2) + 3x = 4x(x + 2)\).
  2. \(6x + 6 = 4x^2 + 8x \Rightarrow 4x^2 + 2x - 6 = 0 \Rightarrow 2x^2 + x - 3 = 0\).
  3. \(\Delta = 1 + 24 = 25\) → \(x = \frac{-1 \pm 5}{4}\) → \(x = 1\) o \(x = -\frac{3}{2}\).
  4. Ninguna anula los denominadores: ambas son válidas.

3. Ecuaciones irracionales

Se aísla la raíz en un miembro, se elevan ambos miembros al cuadrado y se comprueban las soluciones (al elevar al cuadrado pueden aparecer soluciones falsas).

Ejemplo: \(\sqrt{x + 7} = x + 1\)
  1. Elevamos al cuadrado: \(x + 7 = x^2 + 2x + 1 \Rightarrow x^2 + x - 6 = 0\).
  2. \(x = 2\) o \(x = -3\).
  3. Comprobamos: \(x = 2 \Rightarrow \sqrt{9} = 3\) ✓. \(x = -3 \Rightarrow \sqrt{4} = 2 \neq -2\) ✗.
  4. Solución: \(x = 2\).

Retos

  1. \(x^4 - 5x^2 + 4 = 0\) (Sol.: ±1, ±2)
  2. \(x^4 - 16 = 0\) (Sol.: ±2)
  3. \(\sqrt{2x + 3} = x\) (Sol.: 3)
  4. \(\frac{x}{x - 1} = 2\) (Sol.: 2)
